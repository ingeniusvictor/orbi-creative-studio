# ORBI Creative Studio

ORBI Creative Studio is an ORBI Ecosystem adaptation of the open-source project **Open Generative AI**.

## Project status

**Phase 0 — Baseline Certification**

The goal of Phase 0 is to preserve a verifiable upstream baseline before ORBI-specific changes are introduced.

## Upstream baseline

- Upstream: `Anil-matcha/Open-Generative-AI`
- Upstream branch: `main`
- Baseline commit: `871c1d4ef4e184d7b6b5117147d863d30b656cbb`
- Baseline date: 2026-09-11
- Upstream package version observed: `2.0.0`
- License: MIT

## ORBI direction

Planned ORBI layers include:

- AI Director / orchestration
- Image Studio
- Video Studio
- Cinema Studio
- Voice and lip-sync workflows
- Local/cloud compute routing
- ORBI Edge Mesh integration
- Local-first execution where technically practical

No ORBI-specific functional modifications should be made until the upstream baseline is imported and certified.
